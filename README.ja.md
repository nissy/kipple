# Kipple

![Kipple icon](https://github.com/user-attachments/assets/2c295e8a-2fcd-4102-8e46-75bcbaaa79d9)

Kipple は、macOS 向けのローカル完結型クリップボードマネージャーです。

コピーしたテキストを検索しやすく、編集しやすく、整理しやすい状態で保存します。文章作成、調査、コーディング、フォーム入力、アプリ間の情報移動など、テキストを何度もコピーする作業に向いています。

[最新版をダウンロード](https://github.com/nissy/kipple/releases/latest/download/Kipple.dmg)

## Why Kipple?

Kipple は、単なるクリップボード履歴リストではありません。

- コピーしたテキストを検索してすぐに戻せる
- 重要なクリップをピン留めできる
- Live Editor で貼り付け前や保存前に編集できる
- JSON と YAML をエディタ上で整形できる
- Queue で複数のクリップを順番に貼り付けられる
- OCR で画面上の文字を取り込める
- クリップボード履歴を Mac の中に保存できる

## Features

### Clipboard History

Kipple はコピーしたテキストを自動で保存し、メニューバーから開けるコンパクトなウィンドウに表示します。履歴項目を選ぶと、その内容がクリップボードへ戻ります。

履歴には次の情報を含められます。

- コピーしたテキスト
- コピー日時
- コピー元アプリ
- コピー元ウィンドウ名
- URL 分類
- ピン留め状態
- ユーザーカテゴリ

同じ内容を再コピーした場合は、重複を増やさず既存の項目を先頭へ移動します。

### Search, Pin, and Categories

クリップボード内容とコピー元アプリ名から履歴を検索できます。よく使う項目はピン留めし、組み込みカテゴリや独自カテゴリで整理できます。

Kipple には `None` と `URL` の組み込みカテゴリがあります。名前と SF Symbols アイコンを指定して、独自カテゴリを追加することもできます。

### Live Editor

Live Editor では、現在のクリップボード内容を確認し、編集してから履歴へ保存できます。

できること:

- 現在のクリップボード内容を編集
- 編集したテキストを履歴へ保存
- 前後の空白や改行をトリム
- JSON を整形
- YAML を整形

### Queue Paste

Queue は、複数の履歴項目を指定した順番で貼り付ける機能です。

Queue をオンにして履歴からクリップを選び、`Command + V` を繰り返し押すだけで、Kipple が次の項目へ進めます。Loop モードではキューを繰り返せます。

書式なしで貼り付ける場合は、専用ショートカット（初期値: `Command + Shift + V`）を使います。各操作の直前に対象項目をクリップボードへ用意し、次の操作まではその内容を保持します。キュー終了時も最後の項目を消去しないため、貼り付け先の読み取りが遅れても内容が残ります。

書式なし貼り付けのショートカットは、**設定 → 一般 → 貼り付け**で変更・解除できます。設定と使用には「デバイスの制御とデータへのアクセス」の許可が必要です。許可を取り消すとショートカットは停止し、設定したキーは再許可に備えて保持します。

同じ設定の「書式付き・書式なしを入れ替える」をオンにすると、`Command + V` が書式なし、もう一方のショートカット（初期値: `Command + Shift + V`）が書式付きになります。通常モードとQueueの両方に適用されます。画像・ファイルの `Command + V` はそのまま貼り付けます。もう一方のショートカットを解除すると、入れ替えもオフになります。

通常モードでは、Kippleが元のコピー内容を書式やアプリ独自のデータも含めて一時保持します。書式なしで貼り付けた後も、書式付きのショートカットを押すと元の書式で貼り付けられます。新しいコピーをすると退避データを破棄します。時間経過による自動復元や、貼り付け先アプリの書式なし機能は使用しません。この切り替えにはKippleの起動が必要です。メニューやマウスでの貼り付けには、その時点のクリップボードの書式が使われます。

フォーム入力、定型データの転記、複数の値をアプリ間で移す作業に便利です。

### Screen Text Capture

Screen Text Capture では、画面上の範囲を選択して macOS Vision OCR でテキストを抽出できます。

認識したテキストはクリップボードへコピーされ、履歴にも保存されます。OCR 処理は Mac の中で完結します。
段落の区切りを保持し、認識した表は表計算ソフトへ貼り付けやすいタブ区切りのテキストとしてコピーします。

### Paste on Selection

Paste on Selection を使うと、履歴項目を選んだときに、直前に使っていたアプリへ直接貼り付けられます。履歴選択と貼り付けをまとめたい場合に便利です。

## macOS 27以降の権限

**Kippleの設定 → 権限**で許可状態を確認し、**システム設定 → プライバシーとセキュリティ**の該当画面を開けます。

| 権限 | 使用する機能 |
| --- | --- |
| 画面収録とシステムオーディオ録音 | 画面テキストキャプチャ（OCR）とコピー元のウインドウ名の取得。OCRでは静止画を取得し、音声は録音しません。 |
| デバイスの制御とデータへのアクセス | Queue・選択してペースト・書式なし貼り付けで、貼り付け先のアプリへ操作を送信。 |

該当画面で **Kipple** を有効にし、Kippleに戻って許可の状態を確認してください。macOSから再起動を求められた場合や「未許可」のままの場合は、Kippleを終了して起動し直してください。それでも「未許可」の場合は、該当する権限の一覧から古いKippleを削除し、現在使っているKipple.appを追加して許可し直してください。署名を変更した場合や、インストール済み版と開発版を切り替えた場合に必要になることがあります。

通常の履歴保存・検索・履歴の再コピーには、これらの許可は不要です。入力監視・オートメーションの許可も不要です。MCPはローカルのUnixソケットで通信するため、ローカルネットワークの許可は不要です。

クリップボードの読み取りは、macOSが別に管理します。**設定 → 権限 → クリップボードへのアクセス**で現在の設定を確認し、失敗した読み取りを再試行できます。macOSの確認画面が出た場合は許可し、制限されている場合はプライバシーとセキュリティでKippleの設定を確認してください。許可へ変更すると、コピーし直さなくても取り込みが復帰します。同じ内容で拒否された読み取りを自動で繰り返すことはありません。

ログイン時起動はmacOSの登録状態を表示します。「承認が必要」の場合は表示されたボタンからログイン項目を開いてください。承認待ちでも、トグルをオフにすると登録解除できます。

## Privacy

Kipple はローカル完結型です。

- クリップボード履歴は Mac の中に保存
- 設定はローカルに保存
- カテゴリはローカルに保存
- OCR は端末内で処理
- 分析なし
- トラッキングなし
- クラウド同期なし

Kipple はクリップボード履歴を外部サービスへ送信しません。

## Installation

1. [Releases](https://github.com/nissy/kipple/releases) から最新版をダウンロードします。
2. `Kipple.app` を Applications フォルダへ移動します。
3. Applications または Spotlight から Kipple を起動します。
4. 必要に応じてホットキーや設定を変更します。

## Requirements

- Apple Silicon（M1以降）搭載のMac
- macOS 27.0 以降

## 開発

`make run` は **Developer ID Application** 証明書で署名した開発版をビルドして起動します。事前にXcode、XcodeGen、秘密鍵を含む署名証明書を用意してください。別の証明書を使う場合は、`make run DEV_CODE_SIGN_IDENTITY="Apple Development" DEVELOPMENT_TEAM=YOUR_TEAM_ID` のように指定できます。

ビルド間で署名の識別情報を統一してください。未署名・アドホック署名では、システム設定でKippleを有効にしても「未許可」になることがあります。署名を変更した場合は、権限の再許可とKippleの再起動が必要になることがあります。
